# Modem y Bluetooth - Presentación Profesional

Presentación visualmente dinámica sobre **Modem** y **Bluetooth**, cubriendo:

- Características principales
- Usos
- Historia y origen
- Diferencias clave

## Cómo visualizar

### Opción 1: GitHub Pages (recomendado)
1. Ve a **Settings → Pages**
2. Source: Deploy from branch `main` / folder `/ (root)`
3. Guarda y espera unos minutos
4. Accede a: `https://pablocardona963-cmd.github.io/modem-bluetooth-presentacion/`

### Opción 2: Local
Simplemente abre el archivo `index.html` en tu navegador.

## Controles

- Flechas ← → o Espacio: navegar slides
- ESC: vista de diapositivas
- F: pantalla completa
- S: notas del presentador (si se agregan)

## Tecnologías

- [Reveal.js](https://revealjs.com/) para las slides
- CSS con gradientes animados y efectos hover
- Diseño moderno y profesional
